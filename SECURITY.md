# Security Policy

## Reporting Security Vulnerabilities

NutriSync is an independent personal open-source project maintained by [@lohith400](https://github.com/lohith400).

If you discover a security vulnerability or believe you have found a sensitive bug, **please do not report it publicly via GitHub Issues**.

Instead, please report it privately through one of the following methods:

1. **GitHub Private Vulnerability Reporting**:
   - Go to the **Security** tab of the repository on GitHub.
   - Click **Report a vulnerability** to submit details privately.

2. **Direct Contact**:
   - Contact the maintainer privately via GitHub profile details ([@lohith400](https://github.com/lohith400)).

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept.
- Any suggested fixes or mitigations.

We will acknowledge your report promptly, investigate the issue, and release a fix as soon as possible.
